# Shesha Gym — measured ground truth (L0)

Capability is **measured, not noted**. This skill regenerates the four data
artifacts every other designer skill consumes. The tooling lives in
`../shesha-form-edit/` (scripts share libraries with the compiler and gates —
they stay together); this skill owns the *process*.

| Artifact | Regenerated by |
|---|---|
| `shesha-form-edit/assets/components-kb/` (115 types, versions, settingsFields) | `scripts/generate-component-kb.js <designer-components src> assets/components-kb` |
| `assets/components-kb/_enums.json` (dropdown values) | `scripts/extract-enums.js --source <same src>` |
| `schemas/form-config.schema.json` (the cheapest gate) | `scripts/generate-schema.js` |
| `assets/measured-capability-matrix.json` (per-setting effects) | `scripts/generate-component-gym.js` + `scripts/run-gym.js` |
| `shesha-design-system/assets/capability-matrix.json` annotations | `scripts/merge-capability.js` (`--dry-run` first) |

## Process

1. **Preconditions**: target backend + adminportal running; in the
   shesha-form-edit folder: `npm install && npx playwright install chromium`.
   The renderer source checkout for the target release must be available
   (`_meta.json` records the pinned commit of the current KB).
2. **KB first when the release changed**: regenerate KB → enums → schema, in
   that order (settings paths must match the KB generation).
3. **Generate + measure**: full run or `--only <types>` for spot checks. The
   runner pushes gym forms to the backend, measures in a real browser
   (variant-vs-baseline diff: geometry, subtree style union, text/attrs,
   canvas signature), flushes the matrix incrementally, and always continues
   past failures. Whole-form crashes → salvage with `--baseline-only --only
   <types>` (renderStatus measured, settings recorded `unknown`).
4. **Merge**: review `merge-capability.js --dry-run` contradictions before
   writing — a categorical contradiction (measured no-op vs hand "renders")
   is a leaky-abstraction bug to investigate, not to overwrite silently.
5. **Verify + commit**: coverage must equal the KB type count; blocks
   (`validate-blocks.js`) and tests (`node --test tests/`) green; commit the
   regenerated artifacts together.

Full procedure, measurement mechanics, and troubleshooting:
[../shesha-form-edit/references/gym.md](../shesha-form-edit/references/gym.md).

## Non-negotiables

- A component that fails to render is **recorded** (`error` /
  `not-registered`), never dropped — coverage is 100% of the KB by definition.
- Effects come only from measurement; `unknown` is honest, a guessed verdict
  is not.
- The measured matrix is the authority; the design-system matrix carries
  technique annotations only.
