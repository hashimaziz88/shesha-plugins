# Reconciliation rules

Every rule is a scripted, anchored, idempotent transform applied through `scripts/lbpush.py` (local only, backed up,
read back). `H<n>` points to `shesha-developer-0-46` `shesha-form-edit/references/render-hazards-046.md`.
Status: **fleet** = rolled out to every LandBank.Crm form on local; **pilot** = applied to named forms only;
**withdrawn** / **rejected** = do not use.
