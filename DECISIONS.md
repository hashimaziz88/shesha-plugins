## No theatre

```
T1  Shipping a script that cannot execute -> g-commands-executable
T2  A gate that warns where the docs say it fails -> g-gate-contract (mutations flip verdicts, not warning counts)
T3  A program that writes despite declaring it refuses to -> D-010, scheduled:WP-5:g-no-literal-hex
T4  A pass with zero coverage -> structural:packages/registry/src/coverage.mjs (D-006)
T5  Claiming coverage of territory never visited -> g-coverage-single-impl + walk.mjs over items/columns/tabs
T6  Lazily-created report families that can vanish -> families() declared up front (D-005) + expectEmpty
T7  A gate wired into nothing -> the gate ratchet in run-gates.mjs (inputPaths must exist and be non-empty)
T8  A documented MUST-strength gate that ships no code -> g-commands-executable + D-002
T9  Resolving a contradiction by annotating it -> D-009 + g-prose-budget
T10 Changelog archaeology in an instruction file -> g-prose-budget archaeology patterns
T11 A prose rule with no enforcing program -> g-decisions (every row names a live or scheduled: enforcer)
T12 An unreproducible generated asset -> scheduled:WP-2:g-registry-provenance (pinned ref; no drive-letter path)
T13 Feeding the builder's self-report to the judge -> D-016, scheduled:BL-008:evaluator-lock
T14 Fuzzy matchers with escape hatches that downgrade failures -> D-011 + exact registry matching
T15 Presenting an unmeasurable quantity as a measurement -> D-014, D-050; unseeable is uninspectable
```
